# Snake — Neon Garden

Un jeu Snake autonome, réalisé en HTML, CSS et JavaScript sans dépendance ni étape de compilation.

## Utilisation

1. Téléchargez ou clonez ce dépôt sur GitHub.
2. Ouvrez `index.html` dans votre navigateur, ou publiez le dossier avec **GitHub Pages**.
3. Jouez avec les flèches directionnelles ou les touches `ZQSD` (les boutons tactiles sont disponibles sur mobile).

Le meilleur score est conservé localement dans le navigateur avec `localStorage`.

## Publication avec GitHub Pages

Dans votre dépôt GitHub, ouvrez **Settings → Pages**, choisissez la branche à publier (généralement `main`) et le dossier `/ (root)`, puis enregistrez. GitHub vous indiquera l’adresse publique du jeu après le déploiement.
